# Machine Learning & Feature Engineering Architecture

This directory houses the core ML and statistical algorithms for SkyGuard AI.

## Structure
- `features/`: Temporal rolling statistics, geodesic neighbor deltas, and multivariate physical relations.
- `pipelines/`: Unsupervised anomaly detection pipelines (Isolation Forest, LOF, robust statistical estimators).
- `synthetic/`: Synthetic anomaly injection generators for controlled benchmarking.
- `evaluation/`: Ground-truth benchmark scorers and metrics.
